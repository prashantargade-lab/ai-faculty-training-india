# Module 2: Assessments, Question Banks & Grading Rubrics

Use these templates to create higher-order thinking questions and transparent evaluation rubrics.

## 1. Bloom's Taxonomy Question Bank
**Prompt to Copy:**
> "Create a balanced question bank for the topic **[Insert Topic]** suitable for a university internal assessment. Include:
> - 5 Multiple Choice Questions (MCQs) testing conceptual application (not just rote memory), with answer keys and brief explanations.
> - 3 Short-Answer Questions (5 marks each) at the 'Analyze' level.
> - 2 Case-Based Long-Answer Questions (10 marks each) at the 'Evaluate' level."

## 2. Analytic Grading Rubric Builder
**Prompt to Copy:**
> "Design an analytic grading rubric for a **[Insert Assignment Type, e.g., Undergraduate Research Seminar / Group Project]** worth 20 marks. 
> 
> Create a table with 4 evaluation criteria (e.g., Conceptual Clarity, Methodology, Critical Analysis, Presentation) across 4 performance levels: Exemplary (5 marks), Proficient (4 marks), Developing (2-3 marks), and Needs Improvement (0-1 marks). Provide specific, observable descriptors for each cell."

## Hands-On Faculty Exercise (15 Minutes)
1. Pick an assignment or project you currently grade manually.
2. Generate a rubric using the prompt above.
3. Test the rubric by pasting a sample student paragraph into Claude and asking: *"Evaluate this sample strictly against the rubric above and suggest constructive feedback for the student."*
