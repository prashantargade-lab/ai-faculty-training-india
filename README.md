# Claude Toolkit for Higher-Education Faculty

An open-access collection of prompt frameworks, hands-on workshop exercises, and teaching templates created for college and university educators in India.

## Workshop Modules
1. **[Module 1: Syllabus & Outcome-Based Education (OBE) Design](./01-syllabus-and-obe-design.md)** – Aligning courses with Bloom's Taxonomy and creating session plans.
2. **[Module 2: Assessments, Question Banks & Grading Rubrics](./02-assessments-and-rubrics.md)** – Designing case-based questions and transparent evaluation rubrics.
3. **[Module 3: Lecture Content Creation & Academic Workflows](./03-teaching-content-and-research.md)** – Creating analogies, bilingual study aids, and research summaries.

Shared openly for educators, trainers, and academic institutions to adapt and reuse in Faculty Development Programs (FDPs).
